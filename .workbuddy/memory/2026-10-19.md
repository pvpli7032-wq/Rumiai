### 顺手修掉一个自己埋的坑（矩阵）

`scripts/run-browser-matrix.mjs` 支持「直接传文件路径」。原实现对 `.ts/.tsx` 走 tsx、`.mjs/.js` 走裸 node，
结果跑 `node scripts/verify-*-browser.mjs` 报 `Cannot find package '@/lib' imported from src/lib/db.ts`——
因为这些脚本顺着 import 链会读到 TypeScript，`@/` 别名只有 tsx 能解析。已改为：只要是文件路径就统一
`node --import tsx <file>`（和 package.json 里这些脚本自身的调用方式一致）。

**记住：矩阵传「文件路径」和传「脚本名」是两条路径**，传脚本名会取 package.json 的命令行
（形如 `node --import tsx scripts/xxx.mjs`），而 `npm test` 这种命令首 token 是 `tsx` 的会被断言拦下，
所以 HTTP 主套件要写 `node scripts/run-browser-matrix.mjs tests/runner.ts`。
