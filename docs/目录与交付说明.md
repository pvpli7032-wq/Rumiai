# 项目目录与交付范围

## 源码和运行资料

| 路径 | 实际用途 |
| --- | --- |
| `src/app` | Next 页面、路由和 HTTP 入口；不同目录中的 page.tsx、route.ts 是框架约定，并非同一份代码的备份 |
| `src/components` | 可复用界面和业务界面组件 |
| `src/lib` | 服务端业务模块与基础设施；其中 ai 是模型接入、用量和成本控制，不是开发工具残留 |
| `prisma` | 数据模型和有序迁移；本地数据库、backups、restores 是持久数据，不能随缓存清理 |
| `public` | 网站静态资源；uploads 是上传数据，不能随构建清理 |
| `deploy` | 宝塔、Nginx、PM2 和 systemd 运维配置，不含真实密钥 |
| `scripts`、`tests` | 初始化、备份、健康检查及隔离验证；AI 测试使用本地模拟供应商，不代表真实模型验收 |
| `docs` | 架构、业务计划、来源、操作说明和实际验收边界 |

## 本机生成内容

| 路径 | 是否参与源码交付 |
| --- | --- |
| `.next` | 开发编译结果，可重新生成，不入 Git |
| `.next-build` | 当前生产构建，npm run build/start 使用，不入 Git；运行中的服务需要保留 |
| `artifacts/next-cache` | 隔离测试编译结果，不入 Git，不与正在运行的开发或生产构建共用 |
| `artifacts` 其他内容 | 验收截图、报告、本地工具和交付归档，不入 Git；不能整目录删除，其中内容需要按用途分别处理 |
| `node_modules` | 锁文件安装出的依赖，不入 Git；部署目标必须安装对应系统的依赖 |

2026-10-13 已确认本地无 Next/验证进程占用后，清理 14 个根目录 `.next-*` 历史测试构建，约 824 MB。保留 `.next` 和 `.next-build`。三个会自行启动开发实例的验证脚本改用 `artifacts/next-cache`，并移除 TypeScript 对旧测试构建路径的引用。不删除数据库、上传、备份或既有验收报告。

## 开发工具配置

`.claude` 的启动、权限及开发技能配置与 `CLAUDE.md` 只在使用 Claude 开发工具时生效。网站不会读取或执行它们；它们不决定用户权限、余额或模型价格。`AGENTS.md` 是本项目的维护约束，不属于产品功能。`.github` 则负责 CI、安全更新及代码协作。保留这些文件不意味着网站在运行额外的 AI 开发工具。

## 商业交付边界

根目录清理是工程整理，不替代业务和上线验收。交付源码以 Git 版本为准，排除环境密钥、数据库、上传、构建、依赖和本地 artifacts；服务器配置和持久数据独立保管。上线进度以《待完成清单》和《任务进度》为准：用户/站点内容/模型后台管理、真实模型与商户验收、正式政策、真机和真实用户灰度仍需完成；聊天收费和异地备份按用户决定等待或暂缓，不能自行标记完成。
