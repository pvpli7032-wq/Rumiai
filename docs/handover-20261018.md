### 部署前必须先解决的坑

发布目录里的 `ecosystem.config.js`：

```js
const root = path.resolve(__dirname, '../..');   // = /www/wwwroot/khui-ai
script: path.join(root, 'scripts/start-production.mjs')
```

从 `releases/payment-amount-20261017/` 算出来是 `/www/wwwroot/khui-ai`，
但 PM2 记录的实际 `pm_cwd` 是**发布目录本身**。说明当前进程不是照这份文件、
按这个 root 启的。新发布照抄会把进程指到没有 app 的目录。

**接手后第一件事：先弄清 `khui-ai` 的真实启动命令**（查 `shared/pm2/dump.pm2`、
`systemctl cat khui-ai-pm2.service`、`pm2 describe khui-ai`），再写新的启动配置。
