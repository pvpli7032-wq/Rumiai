# 充值套餐与活动后台

日期：2026-10-13（Asia/Tokyo）。状态：本地实现及隔离验证通过；真实支付沙箱仍未通过，不等于 G4 完成。

## 已实现

- 用户确定三档：6 元 60、10 元 100、30 元 300 金币，默认无赠送。
- 财务管理员新增/编辑价格、基础/赠送金币、上架、排序和定时活动。两个时间为空表示持续赠送；定时赠送为开始包含、结束不包含。
- 事务保留操作人及修改前后记录，使用版本避免并发覆盖。金额、整数金币、名称及有效日期由金币域校验；路由只负责权限、输入和 HTTP 映射。
- 商城与建单共用活动计算；客户端报价过期则拒绝新建并刷新。旧订单先查幂等键，下架或改价后仍使用原有快照。
- 默认初始化保留管理员修改，下架旧未配置人民币价的种子套餐但不删除；余额和旧订单不变。
- 新迁移仅新增 CoinPackage 的活动时间/版本及 CoinPackageChange，不重写历史迁移。
