# 财务与充值

管理入口为 /finance。查看需要 finance.read，套餐修改需要 finance.packages.write，退款、查单及重试需要 finance.refunds.execute。运营人员权限由管理模块提供，金额和支付状态由金币与支付领域决定。

## 套餐与活动

默认三档为6元60金币、10元100金币、30元300金币。支持新增、编辑、上下架、排序和定时赠币；活动按服务端时刻生效，后台按设备时区输入。版本冲突返回409。旧订单保留价格与金币快照，下架不改变历史订单。初始化仅补缺，不覆盖人工配置。

## 订单、退款与对账

仅支持整单退款。提交后先冻结订单金币；渠道明确拒绝以新流水返还，超时或验签结果未知继续冻结，查单及重试沿用原退款单号。退款默认关闭，不得用浏览器返回结果发币或直接修改余额。

报告在同一只读事务中检查充值和退款流水、负余额及异常，并按1/7/30/90天统计人民币付款、退款金额。未建立历史期初凭证，不据流水合计自动调整余额；异常列表有100条上限和截断标识。

## 成本与指标

AI成本按币种分别汇总；模拟、失败、取消和未知费用分别显示。未知费用不能视为零，估算不能替代供应商账单。预算提示与可选自动熔断归AI领域，后台展示不决定接纳结果。

新注册付费率为同期注册且同期付款用户数除以同期注册用户数，同一用户多笔付款只计一次。退款率为同期付款订单中成功整单退款订单数除以同期付款订单数。零分母返回null。每千次调用成本按非模拟调用次数计算，含失败和取消；有未知费用时不计算。未有完整人民币成本及渠道费用时毛利率为null。

## 验证与待完成

支付检查使用生成的本地密钥、模拟渠道和隔离数据库。历史订单/退款集成、价格快照、活动并发与浏览器验收已记录在待完成清单；真实商户沙箱、渠道账单、手续费仍待验收。聊天扣币等待运营提供成本和价格，方案见[收费方案](收费方案草案.md)。
