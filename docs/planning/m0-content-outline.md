# M0 首发内容纲要与StoryTemplate草案

依据规划书第13章TABLE 12（文本428–432行）；规划书说明是规划示例，不写入现有角色或生产数据。以下每章含2–4节点。

## 闻舟：深夜唱片店《没有寄出的唱片》

### 第1章：封面上的字迹
- 身份：用户是深夜来店访客/临时帮手；闻舟是唱片店主，认出字迹却回避解释。
- 冲突：未寄出的唱片和信件牵出未知收件人；身份仍是隐藏信息。
- 节点：追问或先听；决定原件交谁保管；接受一起找收件人的邀请，或拒绝/延后。
- 结束条件：记录原件归属、已揭示内容、是否接受邀约及未解问题；拒绝也成立。
- 可记录事件：明确选择的原件归属记FACT；明确接受的寻找约定记PROMISE；猜测不记为真相。
- 下章后果：原件归属改变调查方式；未承诺时闻舟不能说用户答应赴约。规划书13章141–146行及TABLE 12。

### 第2章：收件人之前
- 身份：用户延续已确认的原件保管身份；闻舟按已确认约定行动。
- 冲突：出现可查线索，但猜测不得当作已知真相。
- 节点：保留原件时选择带来或描述；选择共同查寄件线索或暂缓；选择联系候选人或继续匿名。
- 结束条件：确认有来源的新线索，或明确暂缓并保留问题。
- 可记录事件：线索及来源消息、联系决定；候选身份有直接证据后才能确认为事实。
- 下章后果：只有联系后才能产生回应；暂缓不能叙述成已联系；保留原件时闻舟不能凭空取出。

## 许棠：旧物修复师《停在凌晨的怀表》

### 第1章：停在00:17
- 身份：用户将怀表带到工作台；许棠是修复师。
- 冲突：怀表停在凌晨且外壳损坏；修复可能读出刻字，也可能改变原状，失主未知。
- 节点：选择修复或保留损坏；确定拆后盖或仅清洁；决定寻找失主或先保管。
- 结束条件：记录授权/拒绝和保管责任；拒绝修复不是失败。
- 可记录事件：现状、明确授权操作、寻找失主约定；未读刻字不记录为事实。
- 下章后果：修复决定影响能否读出刻字；拒绝修复仍有来源调查路线。依据TABLE 12。

### 第2章：刻字与来源
- 身份：用户持有处理决定；许棠只按授权范围行动。
- 冲突：刻字是线索而非失主确认；未修复路径从来源、转交链调查。
- 节点：已修复则选择读取/遮盖/暂不公开；未修复则查来源/等待/结束；对疑似失主选择联系或保留证据。
- 结束条件：确定刻字可见范围或来源调查计划；允许拒绝继续。
- 可记录事件：修复授权、刻字及来源、联系决定；身份未确认则保持候选。
- 下章后果：公开刻字仅在授权范围引用；拒绝修复继续走来源路线。

## 陆遥：夜班电台《没有署名的点歌》

### 第1章：凌晨一点的留言
- 身份：用户是听众/留言协作者；陆遥是夜班主持。
- 冲突：无署名点歌包含私人内容；播出、私下转交、暂缓具有不同隐私后果。
- 节点：允许播出；要求私下转交；暂不处理。
- 结束条件：明确播出授权、私下授权或暂缓；三种均可结束。
- 可记录事件：明确选择的处理方式和约定；私密内容默认不等于已公开。
- 下章后果：只有允许播出才有节目后续；私下内容不能被称为已公开。依据TABLE 12。

### 第2章：播出之后（或没有播出）
- 身份：用户沿用已确认授权；陆遥不得越权公开。
- 冲突：播出路径收到听众反应；私下路径等待转交；暂缓路径需再决定。
- 节点：播出后选择回应/保留匿名/停止；私下选择确认送达或继续保密；暂缓可继续暂缓或授权处理。
- 结束条件：形成授权范围明确的安排；不公开或继续暂缓都成立。
- 可记录事件：播出授权与节目来源、转交状态、新选择；未播出不得记录听众已听到。
- 下章后果：仅公开路径可引用节目反应；私下路径需送达证据；暂缓不产生公开后果。

## StoryTemplate / StoryVersion字段草案

规划书第15章TABLE 14（文本443–450行）：

| 对象 | 字段草案 | 约束 |
|---|---|---|
| StoryTemplate | id, creatorId, characterId, slug, status, activeVersionId | slug唯一；审核与公开状态独立 |
| StoryVersion | id, templateId, version, locale, definition, characterSnapshot | template+version（locale作为版本维度）唯一；发布后不可原地改写 |
| definition建议结构 | title, premise, userIdentity, openingEvent, publicFacts, hiddenFacts, chapters(chapterKey, nodes, endConditions, recordableEvents, consequenceRules), assets, locale, evaluationCases | 每章2–4节点；隐藏事实不得提前泄露；这是规划字段展开，不是现有Prisma字段 |
| 生命周期 | DRAFT → REVIEW → PUBLISHED → RETIRED | 已开始实例固定原版本；依据第12章134–137行 |

这些是V1设计草案；V0只显示真实片段与用户记录，不能宣称已有跨会话剧情记忆（规划书第5章）。
