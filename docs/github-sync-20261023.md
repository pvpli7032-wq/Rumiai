# 新版同步与清理

目标为用户授权的私有仓库 pvpli7032-wq/Rumiai 的 main 分支。当前多应用源码、数据库迁移、运维脚本、测试和验收文档整体同步；旧版 src/prisma 根目录布局不保留在新版文件树中。

数据库、上传目录、环境配置和用户提供的服务器访问资料存入 private-data。用户随后明确要求不加密，最终按明文交付；应用原本的密码哈希与数据库内加密字段不改变。个人 GitHub 授权和部署 SSH 私钥未上传。数据库使用 SQLite 在线一致性导出，不是直接复制可能遗漏 WAL 的数据库文件。

服务器 current 指向 membership-candidate-20261023。经实际 PM2 目录、进程及配置引用检查，移除了五个旧发布目录与冗余源码上传压缩包；当前发布、shared 实际数据库、上传文件及环境文件均保留。旧发布目录为永久删除，源码可从版本历史找回，不能据此声称旧版本可直接回滚当前数据库。

实际数据库 checkout 总闸保持 false；清理后公开会员 API 返回 200。历史验收文件保留当时的来源和限制，不应把它们全部理解为当前状态。
