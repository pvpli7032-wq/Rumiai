# M4-05 付费验证指标

日期：2026-10-12（Asia/Tokyo）。状态：本地指标准备完成，真实小范围付费验证未完成；G4 未通过。

## 结果与统计口径

财务管理员在 `/finance` 按近 1/7/30/90 天查看，沿用独立财务权限及只读事务。

- 新注册用户付费率：所选期间注册且有同期人民币 EZFP 付款记录的用户数 / 所选期间注册用户数。同一人多笔订单只计一次，退款仍属于曾付款用户。
- 付款订单退款率：所选期间付款订单中已有成功整单退款记录的订单数 / 所选期间付款的人民币 EZFP 订单数。待核对、明确拒绝不计完成。分母为零返回 null，页面显示暂无样本。
- 每千次 AI 调用成本：各币种非模拟估算成本 / 非模拟调用次数 × 1000。包含发送、重生成、失败与取消，不能解释为每千次完成对话。成本未知或无调用时返回 null。人民币显示 CNY，各币种不自动换汇。
- 毛利率保持 null：尚无渠道手续费、结算及完整人民币成本。

指标来自本地留存数据，测试数据库不能作为实际付费率。当前没有渠道环境标识，测试和真实环境须使用独立数据库；截止时点统计不是固定观察时长的留存队列分析。

## 影响范围

`src/lib/payments/validation-metrics.ts` 负责用户/订单统计；`src/lib/ai/cost-report.ts` 负责千次成本和截止时间；`reconciliation-service.ts` 在现有事务内组合。`src/components/payment-validation-metrics.tsx` 和财务页负责展示。财务 API 沿用输入/认证/响应边界，无新增接口、开关或数据库迁移。

## 验证

- 类型检查、生产构建通过，86 个静态页面。
- 千次成本测试 2/2，覆盖币种隔离、模拟排除、失败成本、未知成本和零样本。
- 隔离支付/退款集成测试 10/10，增加重复买家、空队列、成本未知及成功退款率断言，保留签名、入账幂等、财务权限、退款一致性覆盖。
- 18784 隔离生产服务的 Chromium 检查通过：付费率 25%、退款率 50%、USD 成本无法计算、CNY 千次成本、原退款流程、390px 布局、权限拒绝清空。UI 使用明确模拟数据；无真实 AI 或支付调用。
