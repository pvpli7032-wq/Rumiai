2026-10-23 会员配置专项实操：实际后台 UI 保存月/季/年临时价格、每日额外回复和聊天收费倍率，后台 API、公开 API 与前台 DOM 均逐套餐验证；退款参数保存及读取验证通过。随后按最新版本恢复原配置并再次读取确认。发现数据库支付总闸原为开启，环境变量关闭不足以代表真实关闭，已通过正式 service 关闭并记录审计；此总闸保持关闭，不恢复旧值。未下单、未调用支付或退款渠道。详情见 validation-server-membership-config.json。

## 会员已接入的实际权益

当前支持每日额外免费回复、聊天收费倍率、角色创建总上限三项。它们分别接入实际计费或创建事务；不允许后台随意新增一个只有文案、没有消费实现的权益编号。

角色创建的公共默认仍是不限制。只有先配置有限公共上限，且会员上限确实更高，这项权益才有实际增益。公共免费额度先使用；普通额度内的行为不假记会员使用。

月会员为 30 个完整 24 小时，季度/年度默认 90/365 天。支付确认后生效，手动续费衔接期限，不自动扣款。订单保存价格、权益、时长及退款参数快照；修改公共配置不追改旧订单。默认支付后 24 小时退款窗口：未消费全退，已消费扣订单快照中一个 24 小时周期的按日费用，向上取整到分。
