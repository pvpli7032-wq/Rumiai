# 账户隐私

## 本人数据导出

个人页导出本人JSON v2，在同一数据库快照读取，显式限定当前认证账号。包含账户资料、会话、本人角色与社区内容、关系引用、奖励、金币和订单退款、AI用量；管理身份新增enabled、角色名称和权限。没有密码、令牌、供应商密钥或他人私有人设；举报证据快照不导出。

## 注销与文件清理

注销要求当前密码、明确确认和保留说明。待核对支付/退款或活跃AI请求阻止注销。事务撤销旧登录，清除本人内容、撤下角色并匿名化账号；保留账务、用量、举报证据与管理审计。最后一位所有者必须先指定另一位所有者。

上传使用受控目录和归属记录，MIME与文件字节一致。私有附件只由其所有者访问；清理不删除他人仍引用的共享文件。注销文件失败可通过ops:closure-files重试，不能整目录清空uploads。历史无归属共享文件仍需核查。

## 验证与运营事项

测试test:m5:export、test:m5:closure使用隔离数据库；对应浏览器命令只允许隔离本机服务。已验证身份限制、凭据排除、跨用户保留、旧会话撤销、迟到写入和并发注销。正式政策、保留期限、年龄准入及版权处置仍需运营确认。备份和恢复见[部署说明](../../DEPLOYMENT.md)。

用户管理启用后记录最近成功登录时间及认证活动时间，活动最多每五分钟刷新一次，不记录IP或设备指纹。历史记录为空时显示尚无记录。本人导出包含这些时间及停用状态/理由；注销清空停用理由和活动时间。整站停用、社区禁言和注销为三个不同状态，停用保留账务且不会代替注销。
