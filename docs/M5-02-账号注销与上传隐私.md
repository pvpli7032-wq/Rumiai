# 账号注销与上传隐私

日期：2026-10-13（Asia/Tokyo）。本地实现与隔离验证通过，整体隐私与上线阶段仍未完成。

## 已完成行为

个人页提供密码、确认文字和保留说明。服务端只处理当前身份，写事务先占用版本，拒绝未结束的支付/退款或 AI 请求。匿名化账号、撤销旧凭据，清除本人聊天、角色文本及附件引用、社区内容、偏好和关系；保留他人聊天/回复、匿名金币余额/流水、订单、AI成本与举报证据。没有扣回或销毁金币。

新增有序迁移 `20261013020000_account_closure`，不注销现有用户；数据库约束防止已认证但迟到的请求重新写入注销账号的内容。跨域清理由各域隐私服务负责，账号模块组合事务。

新上传记录所有者并隔离文件名；注销清理已归属文件。旧无归属且仍有引用的共享文件进入待核查状态，重试命令不强制删除。保留清理状态和注销编号；失败可重试，不能宣称所有存量数据已物理销毁。备份与供应商数据由运营方另行处理。

生产模式下新图片原来返回 404，已改为动态读取。私有素材验证本人身份，公开来源必须属于文件所有者且可见/审核通过；他人引用不会公开私有文件。媒体 Cookie 为 HttpOnly，写 API 不使用 Cookie 登录；私有路径不进 image optimizer 公共缓存，响应不缓存，注销后拒绝读取。登录切换的旧响应不能覆盖新身份。

日志去掉原始错误消息/堆栈和 Prisma 参数，保留路由、错误类型与安全代码。修复注销/退出时个人页自动重定向覆盖明确导航的问题。
