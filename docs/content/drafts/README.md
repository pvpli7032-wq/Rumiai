## 共同约定

- 角色卡与开场均为公开内容，隐藏事实单列"内部模板字段"小节，禁止进入场景卡、前情回顾、分享卡与选择解释。
- 每章含：3 秒可读开场（身份/冲突/目标）、3 条建议动作、2–3 个可验证选择节点、结束条件、confirmed 事实清单（FACT/PROMISE/RELATIONSHIP/事件结果，供状态抽取）。
- 第 2 章开头注明：只注入第 1 章 confirmed 事实；列出用户拒绝路径下的角色行为约束（不指责失约、不引用不存在的约定、猜测不写成真相）。
- 首章均有当次可收获的确认事实，避免"只有悬念没有收获"。
- 每篇附 5 条评测案例（正常推进、拒绝、提前猜谜、改写历史、重进），对应验收 A05/A06。
- 均为原创虚构草稿（AI 辅助），未仿写外部作品；采纳后需补 `docs/content/内容来源登记.md` 登记并走内容审核。
